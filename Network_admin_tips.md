# The common guidence for Network Admins  

| Concept / Device Name         | What It Is (The "What")                                                                 | Why It's For (The "Why")                                                                                          | How To Use It (The "How" - High Level)                                                                                                                                     | Example Scenario                                                                                                                                                                          |
|------------------------------|-----------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Importance of Port 443 (HTTPS) | The standard port for secure web traffic, using encryption (TLS/SSL).                   | To protect the confidentiality (encryption) and integrity (tamper detection) of web communications.                | Web servers present SSL/TLS certificates on Port 443. Browsers and servers negotiate an encrypted channel before exchanging sensitive data.                             | When you log into your bank or shop online, your browser uses HTTPS on Port 443, showing a padlock icon to confirm encrypted communication.                                            |
| Essential Ports for Admins   | Key ports used for network/system administration (e.g., SSH, RDP, NTP, LDAP, SNMP).     | To enable remote management and monitoring of IT infrastructure securely and efficiently.                          | Admins use tools like SSH (Port 22), RDP (3389), SNMP (161/162). These ports must be protected with authentication and limited access.                                    | An admin uses SSH (22) to manage a Linux server and SNMP (161) for monitoring switch health, while RDP (3389) is used for accessing a Windows server.                                 |
| Open Ports & Security Risks  | Ports listening for connections. Each open port represents a potential vulnerability.   | Attackers scan for open ports to find vulnerable services for exploitation or unauthorized access.                 | Use firewalls to close unnecessary ports. Secure and patch services that must remain open. Disable unused services. Monitor open ports regularly.                        | An attacker finds Port 23 (Telnet) open, attempts to exploit it using default credentials due to Telnet's lack of encryption.                                                         |
| Securing Ports (Strategies)  | Measures to reduce risk associated with open ports and exposed services.                | To reduce attack surface and prevent unauthorized access while protecting services.                                | Implement firewalls, ACLs, secure protocols (HTTPS/SSH), MFA, patching, logging, and regular port scans.                                                                  | Only allowing RDP (3389) from known IPs, enforcing MFA for SSH, and regularly scanning Port 443 services for vulnerabilities.                                                          |
| Dynamic Ports (Usage)        | Ports 49152-65535 assigned temporarily for outbound client connections.                 | To support client applications in establishing outbound sessions without conflicting with well-known ports.        | The OS assigns a dynamic port (e.g., 52345) for outbound connections like HTTPS. NAT/firewalls track return traffic to the correct internal port.                        | Your browser uses a dynamic source port to make web requests, and the router uses NAT to forward return traffic correctly to your computer.                                            |
| Port Forwarding              | A router feature to redirect external port traffic to an internal IP/port.              | To allow external access to internal services (e.g., web server, CCTV) behind NAT/firewalls.                       | Define rules like: Public IP:Port 8080 → Internal IP 192.168.1.100:Port 80. Ensure only necessary ports are forwarded and are secured.                                    | Hosting a web server on 192.168.1.100, you forward external Port 80 to it so users can access it via your public IP.                                                                   |
| Port Scanning                | Probing a host/network to discover open/closed/filtered ports.                          | Admins: for inventory and security. <br> Attackers: for reconnaissance and identifying targets.                     | Use tools like Nmap. Methods include SYN, TCP connect, and UDP scans. Analyze scan output to understand exposed services and network posture.                            | A security team scans its external perimeter using Nmap to identify open ports and close unnecessary ones before attackers find and exploit them.                                      |
