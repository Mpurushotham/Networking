Network Concepts
| Concept / Device Name | What It Is (The "What") | Why It's For (The "Why") | How To Use It (The "How" - High Level) | Example Scenario |
|------------------------|--------------------------|----------------------------|----------------------------------------|------------------|
| OSI Model | A conceptual framework with 7 layers (Physical, Data Link, Network, Transport, Session, Presentation, Application) describing network functions. | To standardize network communication and help understand/troubleshoot how different protocols and devices interact at various levels. | It's a reference model, not directly "used" like a protocol. You use it to understand where technologies like Ethernet (Layer 1/2), IP (Layer 3), TCP (Layer 4), HTTP (Layer 7) fit. | When troubleshooting why a website isn't loading, you might think: Is the physical cable plugged in (L1)? Is the switch working (L2)? Is routing okay (L3)? Is the web server responding (L7)? |
| TCP/IP Model | A more practical, widely implemented 4-layer model (Network Interface/Link, Internet, Transport, Application) that maps closely to real-world protocols. | To provide the actual foundation for the internet and most modern networks. It defines the core protocols (TCP, IP, UDP, etc.). | It's the underlying structure. Your OS networking stack implements TCP/IP. You configure IP addresses (Internet Layer) and use apps that rely on TCP/UDP (Transport) & HTTP/DNS (Application). | Every time you browse the web, send an email, or stream video, your device is using the TCP/IP protocol suite to communicate across networks. |
| MAC Address | A unique hardware identifier burned into a Network Interface Card (NIC). Operates at the Data Link Layer (L2). Think of it as a device's serial number. | For device identification on a local network segment (like within the same Wi-Fi network or connected to the same switch). Used for local delivery. | It's usually fixed for a device's network card. Switches use MAC addresses to learn which device is connected to which port and forward frames accordingly. | Your Wi-Fi router uses your laptop's MAC address to send data specifically to your device, distinguishing it from your phone or smart TV on the same Wi-Fi network. |
| IP Address (IPv4/IPv6) | A logical address assigned to devices on a network. Operates at the Network Layer (L3). Think of it as a device's street address on the internet/network. | For routing data across different networks. Allows devices anywhere in the world to find each other. IPv6 overcomes the address limitations of IPv4. | Assigned manually (static) or automatically via DHCP. Routers use IP addresses to determine the best path to send data packets between networks. | When you visit google.com, your computer sends data packets with Google's public IP address as the destination. Routers across the internet use this IP address to guide the data. |
| Subnet Mask | Used with an IP address to define which part is the Network ID and which part is the Host ID. | To divide a larger network into smaller, manageable subnetworks (subnets). Helps organize networks and control traffic flow. | Configured alongside the IP address (manually or via DHCP). Devices use it to determine if a destination IP is on the same local network or needs to be sent to a router (gateway). | Your home network might use 192.168.1.x with a subnet mask of 255.255.255.0. This tells devices that any address starting with 192.168.1 is local; anything else goes to the router. |
| Ethernet | The dominant wired networking technology for Local Area Networks (LANs). Defines physical cables (like Cat6) and Data Link Layer protocols (how frames are sent/received). | To provide reliable, high-speed physical connections between devices on a local network (computers, switches, routers). | Plug devices into switches/routers using Ethernet cables (RJ45 connectors). NICs handle the Ethernet protocols automatically. | Connecting your desktop PC directly to your router with a network cable for a fast, stable internet connection. |
| Switch | A networking device that connects multiple devices on a LAN. Operates primarily at the Data Link Layer (L2). Uses MAC addresses to forward traffic. | To create a local network and efficiently forward data only to the intended recipient device on that network (unlike old hubs that broadcasted everything). | Connect computers, printers, servers, and other switches using Ethernet cables. The switch builds a MAC address table to learn where devices are and forwards frames intelligently. | An office switch connects multiple employee computers, allowing them to share resources like printers and access the internet via a connection to a router, without interfering with each other's traffic. |
| Router | A networking device that connects different networks together (e.g., your home LAN to the internet). Operates primarily at the Network Layer (L3). Uses IP addresses. | To direct traffic between networks and determine the best path for data packets to travel. Often acts as the gateway between a LAN and the wider internet (WAN). | Connects to different networks (e.g., one port to your ISP modem, other ports to your local switch/devices). Configured with IP addresses for each network interface. Manages routing tables. | Your home Wi-Fi router connects your local network (phones, laptops via Wi-Fi/Ethernet) to the internet provided by your ISP, directing traffic back and forth. |
| Firewall | A network security device (hardware or software) that monitors and controls incoming/outgoing network traffic based on security rules. Can operate at multiple layers. | To protect a network or device from unauthorized access, malware, and other threats by filtering traffic based on defined policies (allow/deny). | Placed at network boundaries (e.g., between your LAN and the internet). Configure rules based on IP addresses, ports, protocols, or even application content to permit or block traffic. | A corporate firewall blocks incoming connections on unusual ports to prevent external attacks, while allowing employees to browse the web (HTTP/HTTPS on ports 80/443). |
